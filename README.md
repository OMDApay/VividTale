# VividTale

VividTale is an interactive library of short English stories for children, pairing original picture-book illustrations, gentle life lessons, and browser-based read-aloud narration. Families can search 30 tales, explore kindness and curiosity, choose narration speed and available English voices, and read together safely.

## Highlights

- 30 educational English stories for children and families.
- Original story illustrations with a warm picture-book visual system.
- Search and filters for kindness, courage, and curiosity.
- Read-aloud controls with adjustable speed and available browser voices.
- Family-friendly advertising placement with privacy, cookie, terms, and advertising disclosures.

## Development

```bash
pnpm install
pnpm check
pnpm build
pnpm dev
```

The client is a React 19 and Vite application. The production client output is generated in `dist/public`. Large visual assets are referenced through managed storage URLs rather than committed to the repository.
